Overview

Project Summary

PhishGuard is a beginner-friendly, single-page cybersecurity web application built with Python and Streamlit. It allows users to paste any URL and instantly receive a structured threat-risk estimate — Low, Medium, or High — based on seven heuristic checks applied to the URL's text.

The tool is entirely privacy-safe and client-side: it never visits, fetches, or resolves the submitted URL. All analysis is performed on the raw URL string in memory. Its primary purpose is to educate users about common phishing URL patterns, not to serve as a professional-grade security scanner.

Core Logic

Detection Engine — analyze_url()

The function applies seven sequential checks to the raw URL string. Each check contributes a weighted score to a 0–100 suspicion scale. The final risk tier is determined by thresholds.

#CheckTrigger ConditionScore AddedSeverity
1 Raw IP Address URL matches https?://(\d{1,3}\.){3}\d{1,3} +40 High
2 URL Shortener Domain matches any of 16 known shortener services +30 High
3 Excessive URL Length URL longer than 75 characters +15 Medium
4 Suspicious Subdomains More than 3 dots in the domain part +20 Medium
5 "@" Symbol in URL Any @ character present in the URL +35 High
6 Missing HTTPS URL does not start with https:// +15 Medium
7 Phishing Keywords URL contains: login, signin, verify, update, secure, account, banking, confirm, password, webscr, wallet, reset +10 per keyword Medium
🟢 Low Risk

Score 0 – 39. Few or no indicators. URL appears structurally clean.

🟡 Medium Risk

Score 40 – 69. Some warning signs. Proceed with caution.

🔴 High Risk

Score 70 – 100. Multiple strong indicators. Very likely phishing.

Setup

How to Run

Step 1 — Install Python

Download Python 3.9 or newer from python.org. Ensure pip is available.

Step 2 — Install Dependency

Run pip install -r requirements.txt or simply pip install streamlit.

Step 3 — Launch App

Run streamlit run app.py in the project directory.

Step 4 — Open Browser

Streamlit opens automatically at http://localhost:8501.

Evaluation

Strengths & Limitations

✅ Strengths
  • ✓Zero network requests — completely private
  • ✓Single-file architecture — trivial to deploy
  • ✓Instant real-time analysis
  • ✓Clear, educational explanations per finding
  • ✓Polished, professional dark-theme UI
  • ✓Requires only one pip package
⚠️ Limitations
  • ✗Heuristic only — no live threat intelligence
  • ✗Cannot detect visual cloning or content-level phishing
  • ✗HTTPS presence is not validated (cert, CA)
  • ✗No domain age or WHOIS lookup
  • ✗Keyword list is static — adversarial evasion possible
  • ✗Not suitable as a standalone production security tool
⚠️ Educational Estimate Only. PhishGuard inspects URL text patterns only. It does not visit, fetch, or verify any website content. This tool cannot guarantee a URL is safe or malicious. For real threat detection, use professional tools such as VirusTotal or Google Safe Browsing.
